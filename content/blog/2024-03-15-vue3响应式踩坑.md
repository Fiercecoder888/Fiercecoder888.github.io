# Vue3 响应式踩坑记录

## 解构丢响应性

从 `reactive` 对象里解构出来的字段会丢失响应性，必须用 `toRefs`：

```ts
const state = reactive({ count: 0 })
const { count } = toRefs(state) // 这样才对
```

## ref 和 reactive 怎么选

- 基本类型用 `ref`
- 对象用 `reactive` 或者 `ref` 都行，但别混着解构
- 团队里统一一种风格，比争论哪个更好重要

## watch 的坑

`watch` 监听 `reactive` 对象的属性时，默认是浅监听；要深度监听得显式写 `{ deep: true }`，但这会带来性能开销，能不用就不用。

## 小结

响应式 API 本身不难，难的是记住边界情况。写多了就形成肌肉记忆了。
